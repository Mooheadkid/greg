greg
----

# Why?
greg is my solution to Discord music bots, queuing up any YouTube video and playing it in a voice channel. This project was started in an era when many bots of its ilk were struck down by Discord. 
Note that greg's is extremely janky, and if you examine the code with zero comments, I assure you that you will be disappointed, just like how I am disappointed in greg.

# I want greg, how do I install him?
First off, why? Secondly, I will not let you install greg because this project is really for my own amusement, and making him production ready sanitizes him, in a way that kills the essence of what makes greg, greg.
